># AuroraFireworks教程 


># 💥炸开效果 
- Aurora-在玩家头顶生成一小片星海持续10秒
- AtomicBomb-在玩家前方生成一个爆炸效果持续10秒
- circle-在玩家脚下生成一个法阵爆炸效果持续10秒
- SpellAttack-在玩家前方生成一个移动的法术攻击，爆炸效果持续10秒
